# Python-автоматизация: учебные проекты

Небольшие рабочие проекты на Python: боты, сбор данных, интеграции с API и LLM. У каждого проекта есть README с запуском, тесты (`pytest`) и пример конфигурации без секретов.

| Проект | Что делает | Технологии |
|---|---|---|
| [tg-claude-assistant](tg-claude-assistant) | Telegram-ассистент на Claude API: память диалога, доступ только для своих, запуск как сервис на Linux | aiogram 3, Anthropic SDK, systemd |
| [books-scraper](books-scraper) | Сбор каталога с сайта в CSV и сводка по ценам | Playwright, csv, pytest |
| [crypto-price-alert](crypto-price-alert) | Сигналы о цене криптовалют по публичному API, один сигнал на пересечение уровня | requests, Telegram Bot API, pytest |

## Об авторе
Высшее образование по прикладной математике. Пишу на Python, интересуюсь автоматизацией, ботами и интеграцией с LLM. Ищу удалённую работу или проекты в разработке, коммерческий опыт пока небольшой.

## Как запускать
Каждый проект независим: откройте его папку и следуйте README внутри (виртуальное окружение, `pip install -r requirements.txt`, `.env` из `.env.example`).
