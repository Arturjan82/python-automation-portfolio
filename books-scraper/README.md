# Сбор каталога с сайта (Playwright)

Скрипт на Python открывает сайт в браузере (Playwright), собирает карточки товаров, сохраняет их в CSV и печатает короткую сводку. В качестве примера используется учебный сайт для парсинга [books.toscrape.com](https://books.toscrape.com), он создан специально для таких тренировок.

## Что делает
- проходит по страницам каталога (число задаётся параметром `--pages`);
- из каждой карточки берёт название, цену, рейтинг, наличие и ссылку;
- сохраняет всё в CSV (открывается в Excel);
- печатает сводку: сколько книг, средняя и медианная цена, 5 самых дешёвых книг с рейтингом 4–5, которые есть в наличии;
- если страницы закончились, останавливается сам.

## Запуск
```bash
python -m venv .venv
.venv\Scripts\activate          # Linux: source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
python scraper.py --pages 3 --out books.csv
```

## Тесты
```bash
pytest
```
Проверяются функции разбора цены, рейтинга и наличия, а также сводка (без обращения к сайту).

## Идея для применения
Тот же подход подходит для мониторинга цен на маркетплейсах: заменить адрес и селекторы, запускать по расписанию и сравнивать с прошлым CSV.
