# Уведомления о цене криптовалют

Небольшой скрипт на Python: следит за ценой выбранных монет по публичному API Bybit и присылает сигнал, когда цена пересекает заданный уровень. Ключи API не нужны, торговли нет, только наблюдение за ценой.

## Что умеет
- правила в JSON-файле: для каждой пары можно задать уровень `above` (выше) и/или `below` (ниже);
- **один сигнал на пересечение**: пока цена остаётся за уровнем, повторов нет; когда вернулась обратно, правило снова «заряжается»;
- сигналы в Telegram (если заданы `TELEGRAM_TOKEN` и `TELEGRAM_CHAT_ID`) или в консоль;
- сбой сети или неверный тикер не останавливают проверку остальных пар;
- режим `--once` для разовой проверки (удобно для cron).

## Запуск
```bash
python -m venv .venv
.venv\Scripts\activate          # Linux: source .venv/bin/activate
pip install -r requirements.txt
copy rules.example.json rules.json    # Linux: cp, затем отредактируйте уровни
python alert.py --rules rules.json --interval 60
```
Telegram (необязательно): создайте бота у @BotFather, впишите токен и ID чата в `.env` (образец в `.env.example`).

## Тесты
```bash
pytest
```
Логика сигналов вынесена в `logic.py` и тестируется без сети: срабатывание один раз, повторная «зарядка», уровни выше и ниже, проверка правил.

## Структура
| Файл | Назначение |
|---|---|
| `alert.py` | запрос цены, отправка сигналов, основной цикл |
| `logic.py` | правила и проверка пересечения уровней |
| `rules.example.json` | пример правил |
